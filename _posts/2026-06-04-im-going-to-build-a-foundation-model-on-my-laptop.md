I spend a lot of time reading about foundation models and using them. I've never trained one from scratch. That seems like a gap worth closing.

The plan: build one on my personal laptop. No cloud compute, no GPU budget. Whatever I build has to run on consumer hardware.

That constraint changes everything about the design: model size, data volume, training time. It also forces a specific choice of domain. The genome has to be small enough to tokenize in memory, the data has to be publicly available, and the biological problem has to be real enough that the results mean something.

I've found a case that fits all three. I'll share what it is in a few days.
